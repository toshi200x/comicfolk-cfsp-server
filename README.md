# ComicFolk Sync Protocol Server (cfsp-server)

*[English](README.en.md) | 日本語*

[ComicFolk](https://github.com/toshi200x) 用の自宅サーバー実装。RAR/ZIP書庫の解析・ページ抽出・サムネイル生成・読書履歴/タグ/しおり等の同期をサーバー側で一括して行い、クライアント（ComicFolkアプリ）は解析処理を持たずサーバーに問い合わせるだけで済むようにする。

- 追加インストール不要の純JVM実装（SQLiteドライバも含めてjarに同梱済み）
- Windows / Linux / macOS のいずれでも同じ手順で動作
- 1サーバー = 1ユーザー想定のセルフホスト

このリポジトリは**ビルド済みバイナリの配布のみ**を行っています。ソースコードは非公開です。

## ダウンロード

[Releases](../../releases) から最新版の `cfsp-server-<version>.zip` をダウンロードしてください。

## 必要要件

- **Java 17以上**（JRE/JDKいずれでも可。古いJavaだと`UnsupportedClassVersionError`という分かりにくいエラーになるので注意）
- （任意）**ffmpeg**（バージョン5.0以降推奨） — AVIF形式の書庫のサムネイル生成にのみ使う。無くても他の全機能（JPEG/PNG等のサムネイル含む）は問題なく動作する

## 起動

zipを展開し、ランチャーを実行するだけ。

```
# Linux/Mac
./bin/cfsp-server

# Windows
bin\cfsp-server.bat
```

起動すると管理画面（既定で `http://<このマシンのアドレス>:7878/`）が立ち上がる。

## 初回セットアップ

1. ブラウザで管理画面を開くと、まず**管理画面用パスワードの設定**を求められる（8文字以上）。
2. パスワードを設定してログインすると、ダッシュボードで**ライブラリソース**（書庫が入っているフォルダ、複数可）を指定する。フォルダ選択UIから辿るか、パスを直接入力して保存する。
3. 保存すると接続トークンが自動発行され、そのままサーバー再起動無しで本棚API（既定で8787番ポート）が起動する。
4. ダッシュボードに表示されるQRコードをComicFolkアプリの「サーバー追加」画面で読み取ると、アドレス・トークンをまとめて登録できる。

## データの保存場所

設定ファイル・インデックスDB・サムネイル画像は、**実行時のカレントディレクトリではなく**、既定でホームディレクトリ配下の固定フォルダに保存される。

```
~/.comicfolk-sync-server/
  cfsp-admin.properties   # 管理画面のパスワード・ライブラリソース・接続トークン等
  cfsp-index.db           # 永続インデックス（SQLite。履歴・タグ・しおり等もここに含まれる）
  thumbnails/             # 生成済みサムネイル画像
```

このため、新しいバージョンへアップデートする際は `bin/`・`lib/` を含む展開先ディレクトリを丸ごと入れ替えるだけでよく、どこで展開・実行しても上記のデータは引き継がれる。

保存先を変更したい場合は環境変数で上書きできる。

| 環境変数 | 内容 | 既定値 |
|---|---|---|
| `CFSP_DATA_DIR` | データディレクトリ自体 | `~/.comicfolk-sync-server` |
| `CFSP_ADMIN_CONFIG_PATH` | 設定ファイルのパスのみ個別に上書き | `$CFSP_DATA_DIR/cfsp-admin.properties` |
| `CFSP_DB_PATH` | インデックスDBのパスのみ個別に上書き（サムネイルはこのファイルと同じディレクトリに保存される） | `$CFSP_DATA_DIR/cfsp-index.db` |
| `CFSP_ADMIN_PORT` | 管理画面のポート | `7878` |
| `CFSP_RESCAN_INTERVAL_SEC` | ライブラリの定期再スキャン間隔（秒） | `300` |

## ポート

| ポート | 用途 |
|---|---|
| 7878 | 管理画面（Web UI）。`CFSP_ADMIN_PORT`で変更可 |
| 8787 | 本棚API（ComicFolkアプリが接続する側）。既定値のみで、現状ダッシュボードから変更するUIは無い。変更する場合は`cfsp-admin.properties`の`api.port`を直接編集するか、`CFSP_PORT`環境変数を指定して起動する |

いずれもLAN内・Tailscale等のVPN経由での利用を想定しており、インターネットへの直接公開は想定していない。

## サービス化（常駐運用）

現時点では起動スクリプトを直接実行する形のみで、Windowsサービス・systemdユニット・Dockerイメージなどの用意はまだ無い。長時間の常駐運用が必要な場合は、OS標準の仕組み（Windowsならタスクスケジューラや NSSM 等でのサービス化、Linuxならsystemdユニット化）を各自で用意すること。

## 既知の制限

- Docker配布・Tailscaleサイドカー同梱は未実装
- 認証はBearerトークン1本のみで、複数端末ごとの個別発行・失効機能は未実装
- サムネイル同期APIは差分同期に未対応（全件取得のみ）
