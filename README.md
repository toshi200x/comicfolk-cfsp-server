# ComicFolk Sync Protocol Server (cfsp-server)

*[English](README.en.md) | 日本語*

[ComicFolk](https://github.com/toshi200x) 用の自宅サーバー実装。RAR/ZIP/自炊PDFの書庫の解析・ページ抽出・サムネイル生成・読書履歴/タグ/しおり等の同期をサーバー側で一括して行い、クライアント（ComicFolkアプリ）は解析処理を持たずサーバーに問い合わせるだけで済むようにする。

- Java以外の追加インストール不要（SQLiteドライバ等もすべて同梱済み）
- Windows / Linux / macOS のいずれでも同じ手順で動作
- 1サーバー = 1ユーザー想定のセルフホスト
- 管理画面からワンクリックで新しいバージョンに更新できる（v0.1.27以降）
- 本ごとの余白カット・画像補正の設定をサーバーに保存し、複数の端末で共有できる（v0.1.29以降、ComicFolkアプリv1.24以降）
- 管理画面のQRコードを読み取るだけでアプリに登録できる（v0.1.35以降、ComicFolkアプリv1.24以降）
- サムネイルの表紙を、白紙のページやカバーのスキャンを見分けて選ぶ。自動作成のサムネイルは、管理画面から全蔵書を、アプリからフォルダ単位・本1冊ごとに作り直せる（v0.1.35以降。アプリからの作り直しはComicFolkアプリv1.24以降）

このリポジトリは**ビルド済みバイナリの配布のみ**を行っています。ソースコードは非公開です。

## ダウンロード

[Releases](../../releases) から最新版の `cfsp-server-<version>.zip` をダウンロードしてください（同じ場所にある `.zip.sig` は電子署名のファイルで、手動で導入する場合は不要です）。

## 必要要件

- **Java 17以上**（JRE/JDKいずれでも可。古いJavaだと`UnsupportedClassVersionError`という分かりにくいエラーになるので注意）
- （任意）**ffmpeg**（バージョン5.0以降推奨） — AVIF形式の書庫のサムネイル生成にのみ使う。無くても他の全機能（JPEG/PNG等のサムネイル含む）は問題なく動作する

## 起動

zipを展開し、`bin` フォルダの起動スクリプトを実行する。

```
# Linux/Mac
./bin/cfsp-server

# Windows
bin\cfsp-server.bat
```

起動すると管理画面（既定で `http://<このマシンのアドレス>:7878/`）が立ち上がる。

- 管理画面からの更新・再起動は、この起動スクリプトが行う。**必ず `bin` の起動スクリプトから起動する**こと（`java -jar` 等で直接起動すると、管理画面からの更新・再起動が使えない）。
- Javaに渡すオプションは環境変数 `JAVA_OPTS` で指定できる（例: `JAVA_OPTS=-Xmx4g`）。`JAVA_HOME` が設定されていればそのJavaを、無ければ `PATH` 上の `java` を使う。

## 初回セットアップ

1. ブラウザで管理画面を開くと、まず**管理画面用パスワードの設定**を求められる（8文字以上）。
2. パスワードを設定してログインすると、ダッシュボードで**ライブラリソース**（書庫が入っているフォルダ、複数可）を指定する。フォルダ選択UIから辿るか、パスを直接入力して保存する。
3. 保存すると接続トークンが自動発行され、そのままサーバー再起動無しで本棚API（既定で8787番ポート）が起動する。
4. ダッシュボードの「接続トークン & QRコード」で、スマホからつなぐアドレスを選ぶ（自宅のLANなら「LAN」、外出先からもつなぐなら「Tailscale」と書かれたアドレス）。
5. ComicFolkアプリ（v1.24以降）の本棚で「ComicFolk Protocolサーバーを追加」を選び、「QRコードを読み取る」で表示されたQRコードを読み取ると、アドレス・接続トークン・PC名（サーバー名の初期値）がまとめて入力されるので、そのまま登録する。
   - 手入力する場合は、ダッシュボードに表示されている「ホスト:ポート」（例: `192.168.1.10:8787`）と接続トークンを入力する。

### 外出先から接続するには（Tailscaleを推奨）

サーバーのポートをインターネットに直接公開するのは危険なため（下記「ポート」参照）、外出先から接続する場合は、[Tailscale](https://tailscale.com/)（個人利用は無料）のようなVPNを使うことを推奨する。ルーターの設定（ポート開放）も不要になる。

1. サーバーのPCと、ComicFolkを使うスマホの両方にTailscaleをインストールし、同じアカウントでログインする。
2. 管理画面の「スマホからつなぐアドレス」で「Tailscale」と書かれたアドレス（`100.x.x.x`）を選び、表示されたQRコードをアプリで読み取る（手入力の場合は `100.x.x.x:8787` を入力する）。
3. 自宅のLAN用のアドレスで登録済みのサーバーのQRコードを読み取ると、アプリが同じサーバーだと気づき、Tailscale用のアドレスを接続先として追加するか尋ねる（「接続先を追加」から手入力で追加することもできる）。1つのサーバーに複数の接続先を登録しておくと、そのとき一番速くつながる接続先が自動で選ばれるので、自宅でも外出先でも設定を切り替えずに使える。

## 更新

v0.1.27以降は、管理画面の「サーバーの更新」から新しいバージョンに更新できる。

1. 「更新を確認」を押すと、このリポジトリの最新リリースを確認し、新しいバージョンがあれば更新内容を表示する。
2. 「更新して再起動」を押すと、ダウンロード・入れ替え・再起動までを自動で行う（通常1〜2分。その間はアプリから接続できない）。完了すると管理画面が自動で読み込み直され、ログインし直すと更新の結果が表示される。

- 既定では1日1回、新しいバージョンが出ていないかを自動で確認する（管理画面のチェックでオフにできる）。確認するだけで、勝手に入れ替えることはない。
- 新しいバージョンがあると、ComicFolkアプリの設定画面の「お知らせ」にも表示される（設定アイコンにバッジが付く。お知らせに対応したアプリのバージョンが必要）。
- 配布zipには開発者の電子署名が付いており、サーバーは署名を確かめてから入れ替える。署名が一致しない（壊れている・正規の配布物ではない）ファイルでは更新しない。
- 更新後のバージョンが起動直後に異常終了した場合は、自動で元のバージョンに戻して起動し直し、管理画面で失敗を知らせる。直前のバージョンはインストール先の `lib.prev` フォルダに残る。
- 「ファイルから更新」では、手元にダウンロードした配布zip（と `.zip.sig`）をアップロードして更新することもできる（サーバーからGitHubに接続できない環境向け）。

### v0.1.11以前からの移行（1回だけ手動）

v0.1.11以前の起動スクリプトは管理画面からの更新に対応していないため、v0.1.27へは一度だけ手動で入れ替える。

1. サーバーを停止する。
2. v0.1.27のzipを展開し、以後はその展開先の `bin` の起動スクリプトから起動する（タスクスケジューラ等に登録している場合は、起動するパスを新しい展開先に書き換える）。
3. 設定・インデックス・サムネイルは下記「データの保存場所」にあるため、そのまま引き継がれる。

以後は管理画面から更新でき、展開先のフォルダの場所は変わらない（中身だけが入れ替わる）ため、タスクスケジューラ等の設定を書き換える必要はない。

- 起動スクリプト自体の変更が必要なバージョンが今後出た場合は、管理画面にその旨が表示され、そのバージョンだけは同じ手順で手動で入れ替える。

## データの保存場所

設定ファイル・インデックスDB・サムネイル画像は、**実行時のカレントディレクトリではなく**、既定でホームディレクトリ配下の固定フォルダに保存される。

```
~/.comicfolk-sync-server/
  cfsp-admin.properties   # 管理画面のパスワード・ライブラリソース・接続トークン等
  cfsp-index.db           # 永続インデックス（SQLite。履歴・タグ・しおり等もここに含まれる）
  thumbnails/             # 生成済みサムネイル画像
  update/                 # 管理画面からの更新の作業用
```

このため、インストール先（`bin/`・`lib/` のあるフォルダ）を入れ替えても、上記のデータは引き継がれる。

保存先を変更したい場合は環境変数で上書きできる。

| 環境変数 | 内容 | 既定値 |
|---|---|---|
| `CFSP_DATA_DIR` | データディレクトリ自体 | `~/.comicfolk-sync-server` |
| `CFSP_ADMIN_CONFIG_PATH` | 設定ファイルのパスのみ個別に上書き | `$CFSP_DATA_DIR/cfsp-admin.properties` |
| `CFSP_DB_PATH` | インデックスDBのパスのみ個別に上書き（サムネイルはこのファイルと同じディレクトリに保存される） | `$CFSP_DATA_DIR/cfsp-index.db` |
| `CFSP_ADMIN_PORT` | 管理画面のポート | `7878` |
| `CFSP_RESCAN_INTERVAL_SEC` | ライブラリの定期再スキャン間隔（秒） | `300` |

Windowsのタスクスケジューラで「SYSTEM」アカウントとして動かす場合、ホームディレクトリがSYSTEMのものになるため、`CFSP_DATA_DIR` で保存先を明示するとよい。

## ポート

| ポート | 用途 |
|---|---|
| 7878 | 管理画面（Web UI）。`CFSP_ADMIN_PORT`で変更可 |
| 8787 | 本棚API（ComicFolkアプリが接続する側）。既定値のみで、現状ダッシュボードから変更するUIは無い。変更する場合は`cfsp-admin.properties`の`api.port`を直接編集するか、`CFSP_PORT`環境変数を指定して起動する |

いずれもLAN内・Tailscale等のVPN経由での利用を想定しており、インターネットへの直接公開は想定していない。

## サービス化（常駐運用）

Windowsサービス・systemdユニット・Dockerイメージなどの用意はまだ無い。長時間の常駐運用が必要な場合は、OS標準の仕組み（Windowsならタスクスケジューラ、Linuxならsystemdユニット等）で `bin` の起動スクリプトを起動するよう各自で設定すること。

- 管理画面からの更新・「今すぐ再起動」では、起動スクリプトがその場でサーバーを起動し直すため、サービス側の再起動の仕組みに頼らずに動く。
- 起動スクリプトは、サーバーが更新・再起動以外の理由で終了した場合はそのまま終了する（異常終了時の自動再起動はサービス側の設定で行う）。

## 吹き出し翻訳機能の動作環境

ComicFolkアプリ（v1.22以降）の「吹き出しの自動翻訳」は、このサーバーが本のセリフを翻訳する（Google Gemini APIを使用。APIキーはアプリの設定画面で設定し、サーバーには暗号化して渡される）。テキスト領域の検出にONNX Runtimeを使うため、動作するOS・CPUに制限がある。**対応していない環境では翻訳機能だけが無効になり、それ以外の機能はそのまま使える**（無効な理由は管理画面に表示される）。

| OS | CPU | 追加で必要なもの |
|---|---|---|
| Windows | x64 | なし（Visual C++ 実行時ライブラリを同梱しており、PCに無い分だけ自動で補う）。万一読み込めない場合は、管理画面の案内に従い [Microsoft Visual C++ 再頒布可能パッケージ（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe) をインストールする |
| Linux | x64 / ARM64 | なし（glibc 2.27以上。Ubuntu 18.04以降・Debian 10以降・RHEL 8以降など） |
| macOS | Apple Silicon | なし |

Intel Mac、Alpine Linux等のmuslベースの環境、32bit OS、Windows on ARMでは翻訳機能を使えない。

## 既知の制限

- Docker配布・Tailscaleサイドカー同梱は未実装
- 認証はBearerトークン1本のみで、複数端末ごとの個別発行・失効機能は未実装
- サムネイル同期APIは差分同期に未対応（全件取得のみ）
